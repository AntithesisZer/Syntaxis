# 曲线间的面积：求关于$x$的积分

设$s$是曲线$y=f(x)$和$y=g(x)$以及直线$x=a$和$x=b$围成的区域，其中$f$和$g$是连续函数，且对于$[a,b]$内的所有$x$，由$f(x) \geq g(x)$.

```tikz
\begin{document}
\begin{tikzpicture}[>=stealth, scale=1.0]

	\definecolor{curveblue}{HTML}{2A6F97}   % 1. 经典蓝 (原 themeblue，默认主曲线)
	\definecolor{curveorange}{HTML}{D96B27} % 2. 暖赤橙 (互补色，对比最明显)
	\definecolor{curveteal}{HTML}{0D9488}   % 3. 墨青色 (冷色调延伸)
	\definecolor{curvered}{HTML}{9E2A2B}    % 4. 绯红色 (高亮/重点强调曲线)
	\definecolor{curvegreen}{HTML}{386641}  % 5. 苔绿色 (自然稳重)
	\definecolor{curvepurple}{HTML}{5E548E} % 6. 暮紫色 (优雅暗色调)
	\definecolor{curveyellow}{HTML}{B47200} % 7. 赭黄色 (高亮度差异曲线)
	\definecolor{curverust}{HTML}{9C4A2F}   % 8. 赭石棕 (复古暖暗色)

	\definecolor{themeslate}{HTML}{475569} % 坐标系
	\definecolor{themegrid}{HTML}{E2E8F0}  % 网格
	\definecolor{themefill}{HTML}{E6EEF5}  % 填充
	\definecolor{themebkg}{HTML}{F4F6F8}   % 文字背景填充

	% \fill[color=themefill, opacity=0.8] (0,0) -- plot[domain=0:2, samples=50] (\x, {0.5*\x*\x - 1}) -- (2,0) -- cycle;
	\fill[color=themefill, opacity=0.8] (1,4.875) -- plot[domain=1:12, samples=80] (\x,{-1/8 * (\x-6)^2 + 8}) -- (12,1) -- plot[domain=12:1, samples=80] (\x,{1/16 * (\x-4)^2 - 3}) -- cycle;

	% x轴
	\draw[->, color=themeslate, thick] (-1.0,0) -- (14,0) node[right, font=\small] {$x$};
	% y轴

	% 原点

	\draw[domain=-0.5:13.5, samples=80, color=curveblue, very thick]
	plot (\x,{1/16 * (\x-4)^2 - 3});
	\node[color=curveblue, above, font=\small] at (6,8) {$y=f(x)$};
	\draw[domain=-0.5:13.5, samples=80, color=curveorange, very thick]
	plot (\x,{-1/8 * (\x-6)^2 + 8})
	node[below, font=\small] {$y=g(x)$};

	\draw[color=themeslate, thin] (1,4.875) -- (1,-2.4375);
	\draw[color=themeslate, thin] (12,3.5) -- (12,0);

	\foreach \x/\xtext in {1/a}
	\draw[color=themeslate] (\x,2pt) -- (\x,2pt)
	node[below left, font=\small] {$\xtext$};
	\foreach \x/\xtext in {12/b}
	\draw[color=themeslate] (\x,2pt) -- (\x,2pt)
	node[below, font=\small] {$\xtext$};
	
	\node[color=themeslate, font=\scriptsize] at (6.5,2.5) {$S$};
```
