# 函数的原函数

如果函数$F$的导数是函数$f$，则$F$称为$f$的一个原函数.

> [!definition|1] 原函数
> 如果对于区间$I$上的所有$x$都有$F'(x)f(x)$，则函数$F$称为函数$f$在区间$I$上的一个原函数.

原函数并非只有一个. 考虑函数$f(x)=x^{2}$的原函数，我们理所应当地认为$\frac{1}{3}x^{3}$是$f$的一个原函数，但是$\frac{1}{3}x^{3}+1$、$\frac{1}{3}x^{3}-1$也是$f$的原函数.

```tikz
\begin{document}
\begin{tikzpicture}[>=stealth, scale=1.2]

	\definecolor{curveblue}{HTML}{2A6F97}   % 1. 经典蓝 (原 themeblue，默认主曲线)
	\definecolor{curveorange}{HTML}{D96B27} % 2. 暖赤橙 (互补色，对比最明显)
	\definecolor{curveteal}{HTML}{0D9488}   % 3. 墨青色 (冷色调延伸)
	\definecolor{curvered}{HTML}{9E2A2B}    % 4. 绯红色 (高亮/重点强调曲线)
	\definecolor{curvegreen}{HTML}{386641}  % 5. 苔绿色 (自然稳重)
	\definecolor{curvepurple}{HTML}{5E548E} % 6. 暮紫色 (优雅暗色调)
	\definecolor{curveyellow}{HTML}{B47200} % 7. 赭黄色 (高亮度差异曲线)
	\definecolor{curverust}{HTML}{9C4A2F}   % 8. 赭石棕 (复古暖暗色)

	\definecolor{themeslate}{HTML}{475569} % 坐标系
	\definecolor{themegrid}{HTML}{E2E8F0}  % 网格
	\definecolor{themefill}{HTML}{E6EEF5}  % 填充
	\definecolor{themebkg}{HTML}{F4F6F8}   % 文字背景填充

	% x轴
	\draw[->, color=themeslate, thick] (-4.5,0) -- (4.5,0) node[right, font=\small] {$x$};
	% y轴
	\draw[->, color=themeslate, thick] (0,-5.0) -- (0,5.0) node[above, font=\small] {$y$};
	% 原点
	\node[color=themeslate, below left, font=\scriptsize] at (0,0) {${0}$};

	\draw[domain=-2:2, samples=50, color=curveorange, very thick]
	plot (\x,{1/3 * \x ^ 3 + 2})
	node [below right, font=\small] {$\frac{1}{3}x^{3}+2$};

	\draw[domain=-2:2, samples=50, color=curvepurple, very thick]
	plot (\x,{1/3 * \x ^ 3 + 1})
	node [below right, font=\small] {$\frac{1}{3}x^{3}+1$};
	
	\draw[domain=-2:2, samples=50, color=curveblue, very thick]
	plot (\x,{1/3 * \x ^ 3})
	node [below right, font=\small] {$\frac{1}{3}x^{3}$};
	
	\draw[domain=-2:2, samples=50, color=curvegreen, very thick]
	plot (\x,{1/3 * \x ^ 3 - 1})
	node [below right, font=\small] {$\frac{1}{3}x^{3}-1$};
	
	\draw[domain=-2:2, samples=50, color=curverust, very thick]
	plot (\x,{1/3 * \x ^ 3 - 2})
	node [below right, font=\small] {$\frac{1}{3}x^{3}-2$};

\end{tikzpicture}
\end{document}
```
