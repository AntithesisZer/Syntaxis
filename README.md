# Syntaxis

一个数学、计算机笔记。

### 相关内容

- 数学：微积分、线性代数、概率论
- 计算机：数据结构与算法、计算机系统、计算机组成原理、计算机网络

### 使用说明

请自行下载Obsidian客户端和本仓库，通过Obsidian客户端打开本仓库顶层文件夹即可。

### 特殊说明

该仓库仅被作笔记的远程备份仓库。

该笔记仅有极少数图像为AI生成，其余所有内容或许会参考AI生成的内容，但都没有直接使用AI生成的内容。

笔记结构高度依赖主要参考资料的目录（但不会完全与原书结构一致），部分内容被认为是“不必要的”，但为了保持结构的完整性，仍然编写了对应部分内容的章节，但内容为空。

笔记中的一部分内容被认为是过于“浅薄”的，会补充一些内容，它们会被用标签#Extended标注出来。例如，在微积分的换元法中补充了测度论的内容，但这样的内容仅仅作为主题内容（微积分）的补充，补充的内容（测度论）很有可能是不够严谨也不够详尽的。这样的补充可能是一些说明性的段落，也有可能是不存在于主要参考资料中的章节，甚至可能会为了补充延伸的内容编写独立的.md文件。此时，笔记的编写更多考虑内容的完整性、严谨性，可能会覆盖掉主要参考资料原本的行文结构。

笔记中的图像通过tikz完成，部分图像被认为与笔记内容高度相关，但由于过度复杂、被认为没有必要或渲染出的图像质量不佳，因此不会出现在笔记中。

笔记的编辑过程中大量使用了[Latex Suite](https://github.com/artisticat1/obsidian-latex-suite)插件辅助编辑。插件中默认的snippets已被修改，仅符合作者编辑习惯，比如现在支持了所有的希腊字母，其中包括所有变体，对大写斜体进行了补全。
如需自己编辑，请自行修改根目录下的syntaxis_snippets.js和syntaxis_snippets_variables.js，或在obsidian的插件设置界面修改。
