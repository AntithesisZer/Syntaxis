# Syntaxis

数学、计算机笔记的远程备份仓库。

### 相关内容

- 数学：微积分、线性代数、概率论
- 计算机：数据结构与算法、计算机系统、计算机组成原理、计算机网络

### 使用说明

请自行下载Obsidian客户端和本仓库，通过Obsidian客户端打开本仓库顶层文件夹即可。

### 特殊说明

笔记结构高度依赖主要参考资料的目录（但不会完全与原书结构一致），部分内容被认为是“不必要的”，但为了保持结构的完整性，仍然编写了对应部分内容的章节，但内容为空。

笔记中的图像通过tikz完成，部分图像被认为与笔记内容高度相关，但由于过度复杂、被认为没有必要或渲染出的图像质量不佳，因此不会出现在笔记中。
